# Lore Continuity Checklist

Use this checklist when proposing, approving, or recording substantial new campaign lore.

## Before approval
- [ ] Check the Canon Register and Current World State.
- [ ] Check the relevant detailed record and decision log.
- [ ] Check the Names & Terminology Index for duplicate or conflicting names.
- [ ] Check the Open Questions Register so intentional mysteries are not accidentally answered.
- [ ] Check chronology, ages, succession, geography, travel, and relationships where relevant.
- [ ] Check consistency with Pathfinder First Edition mechanics unless a deliberate house rule is approved.
- [ ] Check the high-medieval technology boundary.
- [ ] Check that inspiration has not become a direct copy of another setting.
- [ ] Separate objective GM truth, public facts, rumors, propaganda, and player knowledge.
- [ ] Identify any conflicts and present them to the GM instead of silently resolving them.

## When approved
- [ ] Update the detailed lore record.
- [ ] Update the Canon Register if the fact changes the setting baseline.
- [ ] Update the Current World State if it changes the current snapshot.
- [ ] Update the Decision Log with rationale and superseded material.
- [ ] Update the Names & Terminology Index if a named entity is introduced.
- [ ] Update the Open Questions Register with questions created or resolved.
- [ ] Add a dated entry to the campaign changelog.
- [ ] Record visibility: GM_ONLY, PLAYER_SHARED, or PUBLIC.
- [ ] Record provenance: source document, GM decision, or session event.

## After each session
- [ ] Separate what happened at the table from what characters believe happened.
- [ ] Record NPC, faction, house, location, inventory, quest, and relationship changes.
- [ ] Record dates and elapsed time.
- [ ] Record player discoveries separately from GM-only truth.
- [ ] Add new unresolved questions and consequences.
- [ ] Check for contradictions with earlier sessions before advancing the world.
