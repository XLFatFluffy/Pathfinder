# Names & Terminology Index

Use this index before naming a new person, place, house, faction, title, religion, historical event, or cultural term. Its purpose is to prevent duplicate names, accidental reuse, and spelling drift.

## Naming rules
- Preserve one official spelling for every established name.
- Record aliases, former names, translations, and common mispronunciations separately.
- Do not promote provisional legacy names from the imported source Bible into current canon.
- Mark names as GM-only when revealing them would expose secrets.
- A name can be reserved without its associated lore being established.
