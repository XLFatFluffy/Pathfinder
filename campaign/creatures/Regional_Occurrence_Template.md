# Regional Creature Occurrence Template

Use one occurrence record for each creature's relationship to a named region or habitat. Do not duplicate the master creature entry.

- **Occurrence ID:** `creature-id.region-id`
- **Creature record:** link to master creature record.
- **Region or habitat:** established geographic name.
- **Status:** ESTABLISHED / OBSERVED / DOCUMENTED / REPORTED / RUMORED / PROPOSED / UNKNOWN.
- **Frequency:** COMMON / UNCOMMON / RARE / SEASONAL / UNIQUE / EXTINCT / UNKNOWN.
- **Evidence:** cite encounter, dated session, document, report, or rumor.
- **Season:** if known.
- **Habitat details:** supported facts only.
- **Public understanding:** distinguish folklore from confirmed knowledge.
- **GM-only notes:** hidden behavior or uncertainty.
- **Last reviewed:**

A single sighting normally supports OBSERVED at that location, not COMMON throughout the region. A report may be recorded without confirming the creature's presence. Do not create an occurrence merely because the habitat seems suitable.
