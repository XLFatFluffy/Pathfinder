# History and Timekeeping

This directory contains the setting's historical foundation, chronology, calendar conventions, and dating references.

## Current records

- [World History](World_History.md) — established historical foundation and chronology, with unresolved dates and details explicitly identified.
- [Campaign Calendar](Calendar.md) — established working calendar, dating convention, festivals, and Session One date.
- [Campaign Timeline](Campaign_Timeline.md) — chronological framework linking established historical events to the current campaign date.

Preserve approximate historical dates as approximate. Do not infer exact dates from broad chronology; the current campaign date is the approved bookkeeping anchor in `Calendar.md`.
