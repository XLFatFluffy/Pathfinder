# Location Dossiers

This directory holds location-centered records. Each major settlement or region may have its own subdirectory so that its local history, institutions, people, economy, factions, routes, and current conditions can be understood together without duplicating the global setting records.

## Current locations

- [starting_city/](starting_city/) — Tallowmere, the campaign's starting city, and its surrounding region.

Use the global geography, politics, people, factions, religions, and economy records for setting-wide authority. Location dossiers describe how those subjects operate in a particular place and should link to global records where appropriate.
