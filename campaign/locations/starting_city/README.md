# Tallowmere Location Dossier

This folder is the consolidated GM reference for Tallowmere and its immediate region. It is intentionally location-centered: local government, merchants, faith, criminal networks, neighborhoods, and geography are grouped here because their local interactions matter to play.

## Record boundaries

These files describe Tallowmere-specific facts. They do not replace global authoritative records in `../../politics/`, `../../people/`, `../../factions/`, `../../religions/`, `../../economy/`, or `../../geography/`. Preserve the distinction between canon, GM-only information, public knowledge, rumors, and unresolved details. Do not duplicate a global record merely to make the local dossier appear complete.
