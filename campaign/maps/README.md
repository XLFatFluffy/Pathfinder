# Map Library

Map artwork and structured map metadata belong here. The existing continent atlas is a **provisional visual reference**, not final canon.

## Planned hierarchy

Continent → Kingdom → Region → City → District / Site → Interior map

## Map record requirements

Each map should have:
- Stable map ID and title
- Map type and parent map ID
- Artwork file path
- Image dimensions and coordinate convention
- Map scale / geographic extent when known
- Child-map links and anchor coordinates
- Markers and linked world-record IDs
- Visibility: GM_ONLY, PLAYER_SHARED, or PUBLIC
- Discovery / ownership state where relevant
- Canon status and revision history

## Current source
