# Player World and Rules Suggestions

**Purpose:** A player-facing place to submit ideas for additions, clarifications, and proposed Pathfinder rule amendments.

This folder is for suggestions only. A suggestion is not canon, a promise, or an approved rules change.

## How to submit

Create a Markdown file using the template below. Keep submissions focused and explain the intended benefit to the shared setting or table.

## Suggestion template

- **Title:**
- **Submitted by:**
- **Category:** World lore / Character option / Rules amendment / Quality of life / Other
- **Proposal:**
- **Reasoning:**
- **Expected impact on balance or continuity:**
- **Is this intended for one character or every campaign?**

## GM review

The GM may:

- **Accept** — approve the proposal, possibly with stated limits.
- **Revise** — offer a modified version for consideration.
- **Defer** — hold the proposal until more context is available.
- **Reject** — decline it, with a brief explanation where useful.

The GM checks proposals against established canon, Pathfinder First Edition rules, campaign tone, balance, and consistency between solo campaigns.

Approved setting changes are incorporated into the authoritative campaign records by the GM. Approved table rulings are recorded with their scope so that a ruling for one character does not silently become a universal rule.

Do not submit spoilers, private character information, passwords, or sensitive personal information here. This repository is public.
