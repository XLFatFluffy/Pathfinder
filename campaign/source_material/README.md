# Preserved Source Material

This directory contains original documents and reference files retained for provenance. These files are source material, not the live editable campaign records.

## Preserved files

- `Campaign Bible.docx` — original uploaded Campaign Bible.
- `PATHFINDER WORLD ATLAS & WORLD SIMULATOR.docx` — original world-atlas and simulator reference document.
- `NSNG0001-DeluxeCharacterSheet.pdf` — Pathfinder character-sheet reference.

The editable Markdown Campaign Bible is maintained at [../Campaign_Bible.md](../Campaign_Bible.md). The current authoritative continental map is maintained separately at [../maps/continent_atlas.png](../maps/continent_atlas.png), with its authority and calibration documented in [../maps/continent_reference.md](../maps/continent_reference.md).

Do not overwrite or revise preserved originals when updating working campaign records. If an original is superseded, retain it and document the replacement and reason in the campaign changelog.
