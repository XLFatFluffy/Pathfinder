# Living World Engine — GM Reference

**Status:** Active GM-reviewed operating system  
**Campaign start:** 1 Harvestfall, 243 AC

This folder contains the supporting records used by the Living World Engine. These records are reference and state, not autonomous instructions for NPC behavior.

The engine is deliberately GM-reviewed. It keeps the world responsive without inventing major canon or running an uncontrolled simulation.

## How to use these records

Use the engine when:

- the PCs cause a meaningful change;
- meaningful in-world time passes;
- a quest, project, political pressure, or faction activity needs review;
- the GM needs to determine what changed while the PCs were elsewhere;
- a session produces consequences that need to propagate into the campaign records.

Do not perform a routine continent-wide simulation. Review the smallest relevant set of records.

## State authority

The structured campaign database and dedicated subject records remain authoritative. The GM Campaign Bible is a consolidated reference. Player-facing material is a filtered derivative.

When records conflict, apply the campaign canon hierarchy in `campaign/GM_Campaign_Bible.md` and `campaign/Current_World_State.md`.

## Historical archive

The previous automated/procedural world-turn concept was retired on 9 November 2026. Its records remain because they contain useful established lore and opening-state context.

The current engine replaces that retired process with a GM-reviewed observe → propose → review → record → surface workflow.

## Play-readiness rule

If a consequence cannot be supported by established motive, knowledge, resources, geography, time, custom, or an explicit GM decision, leave it **UNRESOLVED** rather than inventing it.
