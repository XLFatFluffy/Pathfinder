# Legacy GM Reference Archive

**Status:** Retained reference material; not an operating system  
**Scope update:** 2026-11-09

This folder contains dossiers and notes originally organized for a proposed automated world simulation. That system has been retired. The records are retained because they contain useful setting information: political actors, minor houses, institutions, jurisdictions, local issues, projects, rumors, information channels, and the opening-state snapshot.

**Do not run world turns, maintain simulation clocks, or treat these records as instructions for NPC action.** The GM decides what happens based on the campaign's established facts, the passage of in-world time, character choices, and plausible consequences. NPCs have independent lives, but their actions are determined through GM judgment rather than an automated process.

## Historical/administrative records

The actor, issue, project, event, and turn ledgers remain in the archive for provenance and continuity. They are not live simulation databases and should not be advanced as a routine process. Update the appropriate subject record when an actual event occurs in play or the GM explicitly establishes a change.

The former operating framework is summarized in [the retired framework notice](../Living_World_Engine.md).
