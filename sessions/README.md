# Session Archive

Store one Markdown file per played session, using a stable sequence such as `Session_001.md`.

## Suggested session record

- Session number, date, in-world date, and location
- Player attendance and character status
- Summary of events
- NPCs encountered and relationship changes
- Locations visited and discoveries
- Quests started, advanced, completed, or failed
- Purchases, rewards, losses, and inventory changes
- Player decisions and consequences
- World events that occurred independently of the party
- New information learned by players
- GM-only revelations and secrets
- Proposed updates to campaign records
- Canon changes approved by the GM

Keep player-known information separate from GM-only information. Session notes are historical records; do not rewrite past events to make later continuity cleaner.
